# Árbol de Decisión — Encuesta Nacional de Experiencia del Usuario en Salud (ENUS)

Árbol de decisión interactivo (SVG + JavaScript, sin dependencias externas) que representa
la estructura de la ENUS: caracterización sociodemográfica (Parte 1), preguntas comunes
(Parte 2), sorteo Bernoulli 0,8, actor de la atención y asignación aleatoria de módulo
(Parte 3), con una calculadora de tamaño de muestra
integrada.

## Publicado en GitHub Pages

El sitio se sirve desde la carpeta [`/docs`](./docs) en la rama `main`.

URL una vez habilitado GitHub Pages (Settings → Pages → Source: `main` / `docs`):

