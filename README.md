# Árbol de Decisión — Encuesta Nacional de Salud

Árbol de decisión interactivo (SVG + JavaScript, sin dependencias externas) que representa
la estructura de la Encuesta Nacional de Salud: caracterización sociodemográfica, pregunta
trazadora, gestión institucional y módulos finales, con una calculadora de tamaño de muestra
integrada.

## Publicado en GitHub Pages

El sitio se sirve desde la carpeta [`/docs`](./docs) en la rama `main`.

URL una vez habilitado GitHub Pages (Settings → Pages → Source: `main` / `docs`):

```
https://stalynguerrero.github.io/Arbol_ENUS_2026/
```
